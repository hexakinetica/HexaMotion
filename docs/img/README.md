# Screenshots

Reference captures for the HexaCore README live here.

HexaCore is a headless service, so its "screenshot" is a console transcript. Capture a startup log:

```bash
build/bin/HexaCore.exe > docs/img/hexacore_startup.txt 2>&1
```

Save a terminal screenshot as e.g. `hexacore_console.png` and/or keep the text transcript, then embed
it in [`../../README.md`](../../README.md).
